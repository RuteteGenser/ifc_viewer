# For whoever edits the landing page

The app now opens with a welcome screen, so the landing page only has to send people to the app.

- Main button text: **Open the viewer** (nb: **Åpne viewer**). Link: `/app/`. Nothing else is needed: no `?demo=1`, no trial wording that states a length.
- The welcome screen tells the visitor how long the free trial is (the length is set on the server and can change), then opens the viewer, where the sample building is listed.
- If you mention the trial, say "Try free" and leave the number of hours or days out.
- `/app/?demo=1` still opens the sample building directly and skips the welcome screen. Use it only for a "see an example" link, not for the main button.
- Footer links (both exist in Norwegian and English, the page picks the browser language):
  - Terms: `/app/#/legal/terms`
  - Privacy: `/app/#/legal/privacy`
  - Cookies: `/app/#/legal/cookies`
